# Website assets

Only currently used assets are kept in this directory.

- `developer-wave.png`: the companion’s idle hand-wave animation.
- `developer-overhead-wave-v2.png`: the two-handed overhead wave on hover or keyboard focus.

- `axon-delta.png`: the official Delta logo from [Axon’s trademark page](https://www.axon.com/trademarks), downloaded from https://a.storyblok.com/f/133181/450x403/be5fb8b53e/delta-logo.png. The website applies a CSS raised-badge treatment without redrawing the mark.
